## Реализация автора

`Author` содержит три закрытых поля: `name`, `email`, `gender`. Все значения задаются конструктором. Имя и пол неизменяемы, а почту можно заменить методом `setEmail()`.

Для получения данных предусмотрены `getName()`, `getEmail()` и `getGender()`. Метод `toString()` собирает описание автора в одну строку.

В `TestAuthor` создается объект:

```java
Author author = new Author("Всеволод Андреев", "andreev@example.com", 'M');
```

Сначала выводится исходное описание, затем почта меняется на `vsevolod.andreev@example.com`. Программа показывает значения через геттеры и повторно печатает объект. Изменяется только почта, остальные данные сохраняются.

## Реализация мяча

`Ball` хранит координаты `x`, `y` и шаг перемещения по каждой оси. Один конструктор создает мяч в начале координат, другой получает начальные координаты.

Координаты читаются через геттеры. Методы `setX()`, `setY()` меняют их по отдельности, а `setXY()` меняет обе сразу.

Движение реализовано двумя способами:

- `move(xDisp, yDisp)` перемещает мяч на переданное смещение.
- `setXYSpeed()` сохраняет шаг движения, после чего `move()` без параметров использует эти значения.

В `TestBall` создаются два независимых мяча. Первый начинается в точке `(12, 8)`, второй начинается в `(0, 0)`. После смещения `(-2, 4)` первый оказывается в `(10, 12)`.

Затем положение первого мяча устанавливается в `(20, 10)`, шаг задается как `(3, -1)`. Два вызова `move()` приводят его в `(26, 8)`. Координаты второго мяча остаются нулевыми: изменение одного объекта не меняет другой.

## Как связаны код и теория

Закрытые поля и открытые методы показывают инкапсуляцию. Конструктор отвечает за начальное состояние объекта. Несколько конструкторов и варианты `move()` показывают перегрузку: имя одинаковое, параметры разные. `toString()` переопределяет метод, унаследованный от `Object`.

На UML знак `-` обозначает закрытый доступ `private`, знак `+` обозначает открытый доступ `public`. Поля и сигнатуры методов из диаграммы перенесены в классы. Дополнительные методы движения учитывают текстовое описание мяча.

## Как запустить

Проект рассчитан на JDK 17 или новее. В IntelliJ IDEA нужно открыть папку этой работы, выбрать JDK и при необходимости отметить `src` как Sources Root. Затем запустить `main` нужного класса.

Для сборки из терминала используется `sh build.sh` в Linux или `build.bat` в Windows. Скомпилированные классы появляются в `out`.

```bash
java -cp out edu.mirea.pr2.TestAuthor
java -cp out edu.mirea.pr2.TestBall
```
